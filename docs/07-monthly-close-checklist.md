# Monthly Close Checklist (One-Page)

> Print this, or re-copy it into your notebook. Full walkthrough with explanations: `docs/03-monthly-close.md`. This checklist is education, not tax advice.

```
MONTHLY CLOSE — ________ (month, year)      started: ____:____
================================================================
[ ] 1. GATHER (~5 min)
      - Timer set for 30 min:  yes / no
      - Bank statement for the month
      - Ledger / fill-in worksheet
      - Receipt tray + email-receipts folder

[ ] 2. MATCH (~10 min)  — go down the bank statement:
      [ ] Every line is in my ledger, amounts agree
          (or was added just now — which account?
           Income / Operating / Big / Pay Me / Detail note)
      [ ] Ledger lines missing from statement  -> "cleared
          next month" note, no editing history
      [ ] Zero unexplained lines left (or the residue has a
          Detail note describing what I checked)

[ ] 3. FOOT THE COLUMNS (~5 min)
      Income             $ __________
      Operating Expenses $ __________
      Big Purchases      $ __________
      NET PROFIT (cash)  $ __________   = income - operating - big
      (Pay Me and Set-Aside are NOT in any of these.)

[ ] 4. JAR CHECK (~3 min)
      [ ] Set-Aside got its slice this month
          (if not: moved now Y / N — or jar-IOU written on next
           month's page in the amount of $ __________ )

[ ] 5. RECEIPT SWEEP (~5 min)
      [ ] Tray + inbox dribs gathered
      [ ] Filed into this month's folder
      [ ] Every item has its two-word "dot" (or "???")
      [ ] Personal-or-duplicate items excluded from business folder

[ ] 6. CLOSE THE BOOK (~2 min)
      [ ] Four numbers copied onto the Yearly Tracker
      [ ] Ledger page dated + initialed
      [ ] One sentence on how this month felt money-wise:
          ________________________________________________

      STOP. 30 minutes are up. Anything unresolved gets a
      Detail note and a next-month appointment — not an
      all-nighter.   finished: ____:____
================================================================
SURPRISES THIS MONTH (anything odd, for next month + CPA Day):
  - ________________________________________________
  - ________________________________________________
```

> **The rule of the timer applies every time:** if the close is still unfinished at 30 minutes, stop, note where you stopped, and continue tomorrow with fresh eyes. Slow-and-finished beats fast-and-wrong.
