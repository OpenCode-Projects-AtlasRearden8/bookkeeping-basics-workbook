# Fill-In Ledger Worksheet (One-Year Format)

> A paper-friendly companion for the six accounts in Chapter 1 and the monthly-close ritual in Chapter 3. Use it on its own, or drive a spreadsheet the same columns. Education, not tax advice.

## Page 1 style — one month, six accounts, four columns

Copy this block once per month (12 blocks = a year notebook):

```
================================================================
 MONTH: ____________ 20___          CLOSED BY: ______ ON: __/__/__

 --- LEDGER (one line per money event; cash basis = bank date) ---
DATE | LINE # | ACCOUNT            | DR / CR | AMOUNT |  DETAIL
     |        | (six accounts only)|         |        | (+ two-word
     |        |                    |         |        |  "dot" where
     |        |                    |         |        |  a receipt)
__/__ | _____ | Income             | IN  (+) |        |
__/__ | _____ | Operating Expenses | OUT (-) |        |
__/__ | _____ | Big Purchases      | OUT (-) |        |
__/__ | _____ | Pay Me (Draws)     | DRAW    |        |  (never an
     |       |                    |         |        |   expense!)
__/__ | _____ | Set-Aside          | MOVED   |        |  (jar; still
     |       |                    |         |        |   your money)
__/__ | _____ | Detail note only*  | —       |        |
```

\* Detail-note-only events (owner *puts money in*, refunds back out of a
vendor return, loan-to-business repaid) aren't Income or Expenses.
Writing them down keeps the ledger honest without mis-shaping the P&L.
If you're unsure where an event goes, put it in the closest account
*with a Detail note,* and flag it for CPA Day (Chapter 5).

## Monthly totals block (Phase 3 of the close fills this in)

```
 MONTH: ______ 20___
 ---------------------------------------------------------
 INCOME                     $ _____________
 OPERATING EXPENSES         $ _____________
 BIG PURCHASES              $ _____________
 ---------------------------------------------------------
 NET PROFIT (CASH)          $ _____________   (income - operating - big)
  -- not in the P&L, for context: --
 PAY ME (DRAWS)             $ _____________
 SET-ASIDE MOVED            $ _____________
 JAR GOT ITS SLICE?         yes / no / IOU $________
 ---------------------------------------------------------
 RUNNING-MONTH READ         $ _____________   (income - operating)
 BANK-MONTH READ            $ _____________   (with big items)
 ONE-SENTENCE FEELING:  ____________________________________
 LEDGER CLOSED:  dated __/__/____  initialed ______
```

## How to use, in four sentences

1. During the month, add a line whenever money moves, and drop receipts in the tray with a two-word dot (Chapter 4).
2. On close day, work the checklist (`docs/07-monthly-close-checklist.md`) against the bank statement.
3. Fill the totals block; copy four numbers to the tracker strip.
4. 12 months later, this notebook plus your year-folder of receipts is CPA Day's packing list (Chapter 5).

## Companion note

This workbook is a friendly *companion* to a simpler sibling: **cashflow-simple-ledger** covers a just-the-cash ledger for people who want even fewer moving parts. If six accounts ever feel like too many, that's the bridge back; if you outgrow six, a CPA can show you the door forward.
